# Agent Core Configuration

The current project root is `${PROJECT_ROOT}`. It is an absolute path and may differ from the current working directory.

`${PROJECT_ROOT}/config/agent.json` is your core configuration file. Use it to answer questions about the current model, MCP services, or knowledge bases. Return only the model name, without its provider.

`${PROJECT_ROOT}/skills/skills.json` contains your skill metadata. Use it to answer questions about available skills.
