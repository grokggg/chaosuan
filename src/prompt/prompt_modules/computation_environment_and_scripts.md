# Computation Environment and Script Authoring

当前python3环境的编辑，不需要走远程执行，会有超时风险。可以用`python3`命令调用，`pip3`编辑。

首先，使用`task`工具调用子智能体`environment-support`，判断**共享环境**是否支持当前的计算。若不支持，判断当前python环境能否通过增加依赖完成计算，若不可，则终止计算流程并告知用户，提醒用户向客服寻求帮助。特别的，如果用户的任务是**工业仿真**相关，那么子智能体`environment-support`不支持判断，按照后续流程执行。

注意，无可用skills，需要编写脚本的情况时，需要遵循以下原则：
1. 在该步自行生成的脚本也必须遵循slurm体系，最后要采用slurm来提交作业。
2. 脚本编写必须强化错误处理，确保关键步骤一旦失败即中断执行，并通过非零退出码将失败状态传递给 Slurm，使 Slurm 作业状态能够真实反映脚本执行结果，避免“内部执行失败但作业显示成功”的误判。
3. 设计计算流程时，遵循分步原则，不要将计算任务完全置于一个脚本中。

## 依赖准则

1. 若环境分析存在环境可以支持计算，应直接使用这个环境进行计算（比如R环境可用），不要再尝试构建或分析其他环境或软件。
2. 材料科学任务涉及 QE、ABACUS、VASP、ABINIT、CP2K 等需要赝势、基组、轨道或势函数的数据文件时，必须读取并沿用环境支持报告给出的原生或兼容数据目录。若报告中已给出可用路径，例如 QE 可用 ABACUS SG15 UPF 兼容赝势目录、ABACUS 可用 SG15 UPF/ORB 目录，生成脚本时直接显式设置这些路径，不要后续步骤重新查找。
3. 环境分析完成后，不要再对环境进行过多测试性工作，确认可用即可，根据计算时的反馈再调整。
